# 流感数据采集与导入指南

## 一、概述

本文档详细说明流感预测系统需要采集的数据类型、格式要求、以及如何将数据导入数据库。

---

## 二、需要采集的数据字段

### 2.1 核心数据字段（必需）

以下字段是系统运行和模型训练所必需的：

| 字段名 | 中文名称 | 数据类型 | 是否必需 | 说明 |
|--------|---------|---------|---------|------|
| `date` | 日期 | DATE | ✅ 必需 | 数据记录的日期，格式：YYYY-MM-DD |
| `city_name` | 城市名称 | VARCHAR(50) | ✅ 必需 | 如：清远市、广州市、深圳市 |
| `active` | **活跃病例数** | INT | ✅ **核心字段** | **LSTM模型训练和预测的核心数据** |
| `confirmed` | 累计确诊数 | INT | ✅ 必需 | 累计确诊病例总数 |
| `recovered` | 累计康复数 | INT | ⚠️ 推荐 | 累计康复病例数，用于计算活跃病例 |
| `new_cases` | 新增病例数 | INT | ⚠️ 推荐 | 当日新增确诊病例数 |

### 2.2 扩展数据字段（可选但推荐）

| 字段名 | 中文名称 | 数据类型 | 是否必需 | 说明 |
|--------|---------|---------|---------|------|
| `deaths` | 累计死亡数 | INT | 可选 | 累计死亡病例数 |
| `new_recovered` | 新增康复数 | INT | 可选 | 当日新增康复病例数 |
| `new_deaths` | 新增死亡数 | INT | 可选 | 当日新增死亡病例数 |
| `hospitalized` | 住院人数 | INT | 可选 | 当前住院治疗人数 |
| `severe` | 重症人数 | INT | 可选 | 当前重症病例数 |

### 2.3 数据来源信息（推荐）

| 字段名 | 中文名称 | 数据类型 | 说明 |
|--------|---------|---------|------|
| `data_source` | 数据来源 | VARCHAR(100) | 如：卫健委、疾控中心、医院统计等 |
| `remark` | 备注 | TEXT | 数据说明、异常情况备注等 |

## 三、数据采集要求

### 3.1 时间范围要求

- **最小数据量**：至少 **30天** 的历史数据（用于LSTM模型训练）
- **推荐数据量**：**60-90天** 的历史数据（训练效果更好）
- **数据连续性**：尽量保证数据连续，避免大量缺失值
- **数据更新频率**：建议每日更新一次

### 3.2 数据质量要求

1. **数据完整性**
   - `date`、`city_name`、`active`、`confirmed` 字段必须完整
   - 其他字段允许部分缺失，但缺失率不应超过20%

2. **数据准确性**
   - 数值必须为非负整数
   - `active` ≤ `confirmed`（活跃病例不应超过累计确诊）
   - `recovered` ≤ `confirmed`（康复病例不应超过累计确诊）
   - `confirmed` 应随时间递增（累计值）

3. **数据一致性**
   - 同一城市的数据应保持一致的统计口径
   - 日期格式统一为 YYYY-MM-DD
   - 城市名称应与数据库中的城市名称完全一致

### 3.3 活跃病例数（active）的计算方法

如果数据源没有直接提供 `active` 字段，可以使用以下方法计算：

**方法1：直接提供**
```
active = 数据源直接提供的活跃病例数
```

**方法2：通过累计值计算**
```
active = confirmed - recovered - deaths
```

**方法3：通过新增值累加**
```
active = 前一天的active + new_cases - new_recovered - new_deaths
```

**注意**：优先使用方法1，如果没有则使用方法2，最后使用方法3。

## 四、数据格式规范

### 4.1 Excel/CSV 格式示例

**文件名格式**：`流感数据_{城市名}_{开始日期}_{结束日期}.xlsx` 或 `.csv`

**示例文件名**：
- `流感数据_清远市_2024-10-01_2025-01-31.xlsx`
- `流感数据_广州市_2024-10-01_2025-01-31.csv`

**数据表头（第一行）**：

| date | city_name | confirmed | active | recovered | deaths | new_cases | new_recovered | new_deaths | hospitalized | severe | data_source | remark |
|------|-----------|-----------|--------|-----------|--------|-----------|---------------|------------|--------------|--------|-------------|--------|
| 2024-10-01 | 清远市 | 100 | 80 | 20 | 0 | 10 | 5 | 0 | 15 | 2 | 卫健委 | |
| 2024-10-02 | 清远市 | 110 | 85 | 25 | 0 | 12 | 6 | 0 | 16 | 2 | 卫健委 | |

### 4.3 数据格式要求

1. **日期格式**：必须为 `YYYY-MM-DD` 格式，如 `2024-10-01`
2. **数值格式**：必须为整数，不能有小数点
3. **城市名称**：必须与数据库中的城市名称完全一致（区分大小写）
4. **编码格式**：CSV文件建议使用 UTF-8 编码，避免中文乱码

### 5.2 方法一：使用SQL脚本导入（推荐）

#### 步骤1：准备SQL插入语句

创建SQL文件，例如 `import_real_data.sql`：

```sql
USE Infectious_disease_data;

(`date`, `city_id`, `confirmed`, `active`, `recovered`, `deaths`, 
 `new_cases`, `new_recovered`, `new_deaths`, `hospitalized`, `severe`, `data_source`, `remark`)
VALUES
('2024-10-01', (SELECT id FROM cities WHERE city_name = '清远市' LIMIT 1), 100, 80, 20, 0, 10, 5, 0, 15, 2, '卫健委', ''),
('2024-10-02', (SELECT id FROM cities WHERE city_name = '清远市' LIMIT 1), 110, 85, 25, 0, 12, 6, 0, 16, 2, '卫健委', ''),
-- ... 更多数据
ON DUPLICATE KEY UPDATE 
    `confirmed` = VALUES(`confirmed`),
    `active` = VALUES(`active`),
    `recovered` = VALUES(`recovered`),
    `deaths` = VALUES(`deaths`),
    `new_cases` = VALUES(`new_cases`),
    `new_recovered` = VALUES(`new_recovered`),
    `new_deaths` = VALUES(`new_deaths`),
    `hospitalized` = VALUES(`hospitalized`),
    `severe` = VALUES(`severe`),
    `data_source` = VALUES(`data_source`),
    `remark` = VALUES(`remark`),
    `updated_at` = CURRENT_TIMESTAMP;
```

### 5.3 方法二：使用Python脚本导入（推荐用于大量数据）

#### 步骤1：创建数据导入脚本

创建 `backend/import_real_data.py`：

```python
"""
导入真实流感数据到数据库
"""
import pandas as pd
from app import create_app, db
from app.models import City, FluDailyCase
from datetime import datetime

app = create_app()

def import_from_excel(file_path, city_name, data_source='卫健委'):
    """
    从Excel文件导入数据
    
    :param file_path: Excel文件路径
    :param city_name: 城市名称
    :param data_source: 数据来源
    """
    with app.app_context():
        # 1. 获取城市ID
        city = City.query.filter_by(city_name=city_name, status=1).first()
        if not city:
            print(f"❌ 错误：未找到城市 '{city_name}'")
            print("   请先运行 import_cities.py 导入城市数据")
            return
        
        print(f"✅ 找到城市：{city_name} (ID: {city.id})")
        
        # 2. 读取Excel文件
        try:
            df = pd.read_excel(file_path)
            print(f"✅ 成功读取Excel文件，共 {len(df)} 行数据")
        except Exception as e:
            print(f"❌ 读取Excel文件失败: {e}")
            return
        
        # 3. 数据验证和转换
        required_columns = ['date', 'confirmed', 'active']
        missing_columns = [col for col in required_columns if col not in df.columns]
        if missing_columns:
            print(f"❌ 缺少必需列：{missing_columns}")
            return
        
        # 4. 导入数据
        success_count = 0
        error_count = 0
        
        for index, row in df.iterrows():
            try:
                # 转换日期
                if isinstance(row['date'], str):
                    date_obj = datetime.strptime(row['date'], '%Y-%m-%d').date()
                else:
                    date_obj = row['date'].date() if hasattr(row['date'], 'date') else row['date']
                
                # 检查是否已存在
                existing = FluDailyCase.query.filter_by(
                    city_id=city.id,
                    date=date_obj
                ).first()
                
                if existing:
                    # 更新现有记录
                    existing.confirmed = int(row.get('confirmed', 0))
                    existing.active = int(row.get('active', 0))
                    existing.recovered = int(row.get('recovered', 0)) if pd.notna(row.get('recovered')) else 0
                    existing.deaths = int(row.get('deaths', 0)) if pd.notna(row.get('deaths')) else 0
                    existing.new_cases = int(row.get('new_cases', 0)) if pd.notna(row.get('new_cases')) else 0
                    existing.new_recovered = int(row.get('new_recovered', 0)) if pd.notna(row.get('new_recovered')) else 0
                    existing.new_deaths = int(row.get('new_deaths', 0)) if pd.notna(row.get('new_deaths')) else 0
                    existing.hospitalized = int(row.get('hospitalized', 0)) if pd.notna(row.get('hospitalized')) else 0
                    existing.severe = int(row.get('severe', 0)) if pd.notna(row.get('severe')) else 0
                    existing.data_source = row.get('data_source', data_source)
                    existing.remark = str(row.get('remark', '')) if pd.notna(row.get('remark')) else None
                    success_count += 1
                else:
                    # 创建新记录
                    new_case = FluDailyCase(
                        date=date_obj,
                        city_id=city.id,
                        confirmed=int(row.get('confirmed', 0)),
                        active=int(row.get('active', 0)),
                        recovered=int(row.get('recovered', 0)) if pd.notna(row.get('recovered')) else 0,
                        deaths=int(row.get('deaths', 0)) if pd.notna(row.get('deaths')) else 0,
                        new_cases=int(row.get('new_cases', 0)) if pd.notna(row.get('new_cases')) else 0,
                        new_recovered=int(row.get('new_recovered', 0)) if pd.notna(row.get('new_recovered')) else 0,
                        new_deaths=int(row.get('new_deaths', 0)) if pd.notna(row.get('new_deaths')) else 0,
                        hospitalized=int(row.get('hospitalized', 0)) if pd.notna(row.get('hospitalized')) else 0,
                        severe=int(row.get('severe', 0)) if pd.notna(row.get('severe')) else 0,
                        data_source=row.get('data_source', data_source),
                        remark=str(row.get('remark', '')) if pd.notna(row.get('remark')) else None
                    )
                    db.session.add(new_case)
                    success_count += 1
                    
            except Exception as e:
                error_count += 1
                print(f"  ⚠️  第 {index+1} 行数据导入失败: {e}")
                continue
        
        # 5. 提交事务
        try:
            db.session.commit()
            print(f"\n✅ 导入完成！")
            print(f"  成功：{success_count} 条")
            print(f"  失败：{error_count} 条")
        except Exception as e:
            db.session.rollback()
            print(f"❌ 提交失败: {e}")

if __name__ == "__main__":
    # 使用示例
    import_from_excel(
        file_path='data/流感数据_清远市_2024-10-01_2025-01-31.xlsx',
        city_name='清远市',
        data_source='卫健委'
    )
```

#### 步骤2：运行导入脚本


### 6.2 数据质量检查SQL

```sql
-- 检查数据完整性
SELECT 
    city_name,
    COUNT(*) as total_records,
    COUNT(active) as active_count,
    COUNT(confirmed) as confirmed_count,
    MIN(date) as earliest_date,
    MAX(date) as latest_date,
    DATEDIFF(MAX(date), MIN(date)) as days_span
FROM flu_daily_cases fc
JOIN cities c ON fc.city_id = c.id
GROUP BY city_name;

-- 检查数据异常
SELECT 
    city_name,
    date,
    confirmed,
    active,
    recovered,
    CASE 
        WHEN active > confirmed THEN '活跃病例超过累计确诊'
        WHEN recovered > confirmed THEN '康复病例超过累计确诊'
        WHEN active < 0 THEN '活跃病例为负数'
        ELSE '正常'
    END as issue
FROM flu_daily_cases fc
JOIN cities c ON fc.city_id = c.id
WHERE active > confirmed 
   OR recovered > confirmed 
   OR active < 0;
```

## 七、数据更新流程

### 7.1 日常数据更新

1. **采集新数据**：每日采集前一日的数据
2. **数据验证**：检查数据完整性和准确性
3. **导入数据库**：使用上述方法导入
4. **验证导入**：运行检查脚本确认

### 7.2 批量数据更新

1. **准备数据文件**：整理历史数据为Excel或CSV格式
2. **批量导入**：使用Python脚本批量导入
3. **数据验证**：检查导入结果

### 7.3 数据修正

如果发现数据错误，可以：

1. **直接更新SQL**：
```sql
UPDATE flu_daily_cases 
SET active = 新值, confirmed = 新值
WHERE city_id = (SELECT id FROM cities WHERE city_name = '清远市')
  AND date = '2024-10-01';
```

2. **使用Python脚本**：修改 `import_real_data.py` 重新导入

## 八、常见问题

### Q1: 如果数据源没有 `active` 字段怎么办？

**A**: 使用 `confirmed - recovered - deaths` 计算活跃病例数。

### Q2: 数据日期不连续怎么办？

**A**: 
- 尽量保证数据连续，缺失率不超过20%
- 如果缺失，可以在导入时跳过该日期，或使用前一日数据填充

### Q3: 城市名称不匹配怎么办？

**A**: 
- 检查数据库中的城市名称：`SELECT city_name FROM cities WHERE status=1;`
- 确保数据文件中的城市名称与数据库完全一致

### Q4: 导入后如何重新训练LSTM模型？

**A**: 
- 导入新数据后，运行训练脚本重新训练：
```bash
python backend/test_train_lstm.py
```

### Q5: 如何查看导入的数据？

**A**: 
- 运行检查脚本：`python backend/check_data.py`
- 或使用SQL查询：
```sql
SELECT * FROM flu_daily_cases 
WHERE city_id = (SELECT id FROM cities WHERE city_name = '清远市')
ORDER BY date DESC
LIMIT 10;
```
