# Prophet 模型使用说明

## 一、概述

Prophet是Facebook开发的时间序列预测库，专门用于处理具有季节性、趋势性的时间序列数据。本系统实现了Prophet模型用于流感感染人数的预测。

## 二、模型特点

1. **自动处理季节性**：能够自动识别年度、周度等季节性模式
2. **趋势预测**：能够捕捉数据的长期趋势
3. **鲁棒性强**：对缺失值和异常值有较好的处理能力
4. **无需训练**：与LSTM不同，Prophet不需要预先训练，直接使用历史数据进行预测

## 三、使用流程

### 3.1 使用模型进行预测

**API接口**：`POST /api/predict/run` 或 `POST /api/public/predict`

**请求参数**：
```json
{
  "algorithm": "prophet",        // 算法类型
  "city_name": "清远市",          // 城市名称（必需，用于获取历史数据）
  "days": 7                      // 预测天数
}
```

**说明**：
- Prophet模型会自动从数据库获取该城市的历史数据
- 如果历史数据不足30天，会自动降级为SEIR模型
- 模型会自动识别数据的季节性和趋势

## 四、模型参数

### 4.1 默认参数

- **yearly_seasonality**: `True` - 启用年度季节性
- **weekly_seasonality**: `True` - 启用周季节性
- **daily_seasonality**: `False` - 不启用日季节性（流感数据通常不需要）
- **seasonality_mode**: `'additive'` - 季节性模式（加法模式）
- **changepoint_prior_scale**: `0.05` - 变化点先验尺度（控制模型灵活性）

### 4.2 参数说明

- **yearly_seasonality**: 是否考虑年度季节性（如流感在冬季高发）
- **weekly_seasonality**: 是否考虑周季节性（如周末数据可能不同）
- **seasonality_mode**: 
  - `'additive'`: 季节性影响是加性的（推荐用于流感数据）
  - `'multiplicative'`: 季节性影响是乘性的
- **changepoint_prior_scale**: 控制模型对趋势变化的敏感度，值越大越灵活

## 五、依赖要求

### 5.1 Python包

```bash
pip install prophet
```

**注意**：Prophet的安装可能需要一些时间，因为它依赖一些底层库。

### 5.2 可选安装

如果没有安装Prophet，系统会自动降级为简单预测方法，但无法使用完整的Prophet功能。

## 六、数据要求

### 6.1 最小数据量

- **最少数据量**：至少30天的历史数据
- **推荐数据量**：60-90天的历史数据
- **数据质量**：数据应该连续，避免大量缺失值

### 6.2 数据格式

- 数据必须包含日期和活跃病例数（active字段）
- 日期格式：YYYY-MM-DD
- 数据按日期排序

## 七、与SEIR和LSTM模型的对比

| 特性 | SEIR模型 | LSTM模型 | Prophet模型 |
|------|---------|---------|------------|
| 是否需要训练 | ❌ 不需要 | ✅ 需要 | ❌ 不需要 |
| 数据需求 | 参数配置 | 历史数据（14天+） | 历史数据（30天+） |
| 预测原理 | 数学公式 | 深度学习 | 时间序列分解 |
| 季节性处理 | ❌ 有限 | ⚠️ 需要足够数据 | ✅ 自动识别 |
| 趋势预测 | ✅ 强 | ✅ 强 | ✅ 强 |
| 参数可解释性 | ✅ 高 | ❌ 低 | ⚠️ 中等 |
| 计算速度 | ✅ 快 | ⚠️ 较慢 | ✅ 快 |
| 适合场景 | 理论分析 | 复杂模式学习 | 季节性数据 |

## 八、最佳实践

1. **数据准备**：
   - 确保至少有30天以上的历史数据
   - 数据质量要好，避免缺失值
   - 数据应该包含明显的季节性模式（如果有）

2. **模型选择**：
   - 如果数据有明显的季节性（如流感在冬季高发），优先使用Prophet
   - 如果数据模式复杂，使用LSTM
   - 如果需要理论分析，使用SEIR

3. **预测使用**：
   - Prophet适合短期到中期预测（7-30天）
   - 对于长期预测，建议结合SEIR模型

## 九、注意事项

1. **Prophet依赖**：预测功能需要Prophet库，如果未安装会自动降级
2. **数据量要求**：至少需要30天历史数据才能使用Prophet
3. **季节性数据**：Prophet最适合有明显季节性的数据
4. **计算资源**：Prophet计算速度较快，适合实时预测

## 十、故障排除

### 问题1：预测失败，提示Prophet未安装
**解决**：安装Prophet：`pip install prophet`

### 问题2：历史数据不足
**解决**：确保数据库中有足够的历史数据（至少30天）

### 问题3：预测结果不准确
**解决**：
- 增加历史数据量
- 检查数据质量
- 尝试调整seasonality_mode参数

### 问题4：安装Prophet失败
**解决**：
- 确保已安装C++编译器（Windows需要Visual Studio Build Tools）
- 尝试使用conda安装：`conda install -c conda-forge prophet`
