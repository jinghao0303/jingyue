# SQL文件执行顺序（重要！）

## 📋 完整执行顺序

### 第一步：创建数据库表结构（必须按顺序执行）

```sql
-- 1. 创建地区表（省份、城市、人口）
source backend/database/region_tables.sql;

-- 2. 创建流感相关表（历史数据表、预测结果表等）
source backend/database/seir_flu_tables.sql;

-- 3. 创建LSTM模型训练记录表
source backend/database/lstm_model_tables.sql;
```

### 第二步：导入数据（可选，如果需要训练LSTM）

```sql
-- 导入流感模拟数据（清远市、广州市、深圳市，123天数据）
source backend/database/import_flu_data.sql;
```

### 第三步：清空数据（仅在需要重新导入时使用）

```sql
-- 如果需要重新导入数据，先执行清空
source backend/database/clear_flu_data_simple.sql;

-- 然后重新导入
source backend/database/import_flu_data.sql;
```

## 🚀 快速开始（第一次使用）

```sql
-- 按顺序执行以下4个文件
source backend/database/region_tables.sql;
source backend/database/seir_flu_tables.sql;
source backend/database/lstm_model_tables.sql;
source backend/database/import_flu_data.sql;
```

## ⚠️ 注意事项

1. **执行顺序很重要**：必须先创建表，再导入数据
2. **重复执行**：`import_flu_data.sql` 可以重复执行，会自动更新已存在的数据
3. **VALUES()警告**：执行时可能会有 `VALUES()函数已弃用` 的警告，可以忽略，不影响使用
4. **数据量**：导入后会生成369条记录（3个城市 × 123天）

## 📊 验证数据

执行 `import_flu_data.sql` 后，会自动显示数据统计信息，包括：
- 每个城市的记录数
- 日期范围
- 平均/最大/最小活跃病例数

如果看到3个城市的数据统计，说明导入成功！
