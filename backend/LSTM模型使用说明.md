# LSTM 模型使用说明

## 一、概述

LSTM（Long Short-Term Memory）是一种深度学习模型，用于时间序列预测。本系统实现了LSTM模型用于流感感染人数的预测。

## 二、模型特点

1. **需要训练**：与SEIR模型不同，LSTM模型需要基于历史数据进行训练
2. **数据驱动**：模型通过学习历史数据的模式来进行预测
3. **自动学习**：能够自动捕捉时间序列中的复杂模式和趋势

## 三、使用流程

### 3.1 训练模型

**API接口**：`POST /api/predict/train/lstm`

**请求参数**：
```json
{
  "city_name": "清远市",           // 必需：城市名称
  "epochs": 50,                    // 可选：训练轮数，默认50
  "batch_size": 32,                // 可选：批次大小，默认32
  "validation_split": 0.2,         // 可选：验证集比例，默认0.2
  "historical_days": 60             // 可选：使用多少天历史数据，默认60
}
```

**响应示例**：
```json
{
  "code": 200,
  "msg": "模型训练成功",
  "data": {
    "city_name": "清远市",
    "model_path": "models/lstm_model_清远市_20250101.h5",
    "scaler_path": "models/scaler_清远市_20250101.json",
    "training_history": {
      "final_loss": 0.0123,
      "final_val_loss": 0.0145,
      "final_mae": 15.6,
      "final_val_mae": 18.2
    },
    "data_points": 60
  }
}
```

### 3.2 使用模型进行预测

**API接口**：`POST /api/predict/run` 或 `POST /api/public/predict`

**请求参数**：
```json
{
  "algorithm": "lstm",              // 算法类型
  "city_name": "清远市",            // 城市名称（必需，用于获取历史数据）
  "days": 7                         // 预测天数
}
```

**说明**：
- LSTM模型会自动从数据库获取该城市的历史数据
- 如果历史数据不足14天，会自动降级为简单预测方法
- 如果已训练了该城市的模型，会自动加载使用

## 四、模型架构

### 4.1 网络结构

```
输入层: (batch_size, 14, 1)  # 14天历史数据
  ↓
LSTM层1: 50个单元，return_sequences=True
  ↓
Dropout: 0.2
  ↓
LSTM层2: 50个单元，return_sequences=False
  ↓
Dropout: 0.2
  ↓
全连接层: 25个神经元
  ↓
输出层: 1个神经元（预测值）
```

### 4.2 数据预处理

1. **数据归一化**：使用MinMaxScaler将数据归一化到[0,1]范围
2. **序列构建**：将时间序列转换为监督学习问题（使用过去14天预测下一天）
3. **数据分割**：训练集和验证集按比例分割

## 五、依赖要求

### 5.1 Python包

```bash
pip install tensorflow>=2.8.0
pip install scikit-learn>=1.0.0
pip install numpy>=1.21.0
```

### 5.2 可选安装

如果没有安装TensorFlow，系统会自动降级为简单预测方法，但无法进行模型训练。

## 六、模型文件

训练后的模型会保存在 `backend/models/` 目录下：

- **模型文件**：`lstm_model_{城市名}_{日期}.h5`
- **Scaler文件**：`scaler_{城市名}_{日期}.json`

## 七、与SEIR模型的对比

| 特性 | SEIR模型 | LSTM模型 |
|------|---------|---------|
| 是否需要训练 | ❌ 不需要 | ✅ 需要 |
| 数据需求 | 参数配置 | 历史数据 |
| 预测原理 | 数学公式 | 数据学习 |
| 参数可解释性 | ✅ 高 | ❌ 低 |
| 适应复杂模式 | ❌ 有限 | ✅ 强 |
| 计算速度 | ✅ 快 | ⚠️ 较慢 |

## 八、最佳实践

1. **数据准备**：
   - 确保至少有30天以上的历史数据
   - 数据质量要好，避免缺失值

2. **训练参数**：
   - 初始训练建议使用默认参数
   - 如果过拟合，可以减少epochs或增加dropout
   - 如果欠拟合，可以增加LSTM单元数

3. **模型更新**：
   - 建议定期重新训练模型（如每月一次）
   - 使用最新的历史数据训练

4. **预测使用**：
   - 优先使用已训练的模型
   - 如果数据不足，系统会自动降级为简单预测

## 九、注意事项

1. **TensorFlow依赖**：训练功能需要TensorFlow，如果未安装会自动降级
2. **数据量要求**：至少需要30天历史数据才能训练
3. **计算资源**：训练过程可能需要较长时间和较多内存
4. **模型保存**：训练后的模型会自动保存，下次预测时会自动加载

## 十、故障排除

### 问题1：训练失败，提示TensorFlow未安装
**解决**：安装TensorFlow：`pip install tensorflow`

### 问题2：历史数据不足
**解决**：确保数据库中有足够的历史数据（至少30天）

### 问题3：预测结果不准确
**解决**：
- 增加训练数据量
- 调整模型参数（epochs, batch_size等）
- 检查历史数据质量
