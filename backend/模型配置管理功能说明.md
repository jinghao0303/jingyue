# 模型配置管理功能说明

## 一、功能概述

实现了模型配置管理功能，允许管理员在后台设置默认预测模型，前端公众端根据用户位置自动获取数据并使用配置的默认模型进行预测。

## 二、架构设计

### 2.1 数据流程

```
后台管理 → 设置默认模型 → 保存到数据库
                ↓
前端公众端 → 获取用户位置 → 从数据库获取该城市数据 → 使用配置的默认模型预测
```

### 2.2 核心原则

1. **后台管理模型配置**：管理员在后台选择默认使用的预测模型
2. **前端根据位置预测**：前端根据用户位置（城市）获取对应数据，使用配置的模型预测
3. **数据驱动**：所有数据来自数据库，不硬编码

## 三、数据库变更

### 3.1 新增字段

在 `flu_model_config` 表中添加 `default_algorithm` 字段：

```sql
ALTER TABLE `flu_model_config` 
ADD COLUMN `default_algorithm` VARCHAR(20) DEFAULT 'seir' 
COMMENT '默认预测算法：seir/lstm/prophet';
```

### 3.2 执行SQL脚本

```bash
# 执行数据库更新脚本
mysql -u root -p Infectious_disease_data < backend/database/add_default_algorithm_column.sql
```

或在MySQL客户端中：

```sql
source backend/database/add_default_algorithm_column.sql;
```

## 四、后端API接口

### 4.1 获取默认模型配置（公众端）

**接口**：`GET /api/public/model/config`

**说明**：无需登录，前端公众端使用

**响应**：
```json
{
  "code": 200,
  "data": {
    "default_algorithm": "seir",
    "r0": 1.4,
    "incubation_period": 5.0,
    "infectious_period": 7.0,
    "intervention_factor": 1.0
  }
}
```

### 4.2 获取模型配置（管理员）

**接口**：`GET /api/admin/model/config`

**说明**：需要登录，管理员查看当前配置

**响应**：同上

### 4.3 更新模型配置（管理员）

**接口**：`POST /api/admin/model/config`

**说明**：需要登录，只有超级管理员可修改

**请求参数**：
```json
{
  "default_algorithm": "prophet",  // seir/lstm/prophet
  "r0": 1.4,
  "incubation_period": 5.0,
  "infectious_period": 7.0,
  "intervention_factor": 1.0
}
```

**响应**：
```json
{
  "code": 200,
  "msg": "模型配置更新成功",
  "data": {
    "default_algorithm": "prophet",
    ...
  }
}
```

## 五、前端页面

### 5.1 后台模型配置页面

**路径**：`/admin/model-config`

**功能**：
- 选择默认预测算法（SEIR/LSTM/Prophet）
- 配置SEIR模型参数（R0、潜伏期、传染期等）
- 保存配置
- 查看当前配置信息

**访问权限**：需要登录，只有超级管理员可修改

### 5.2 前端公众端

**路径**：`/public/home`

**功能**：
- 自动获取用户位置（城市）
- 从API获取默认模型配置
- 根据用户位置获取对应城市的数据
- 使用配置的默认模型进行预测

## 六、工作流程

### 6.1 管理员配置流程

1. 登录后台管理系统
2. 进入"模型配置管理"页面
3. 选择默认预测算法（SEIR/LSTM/Prophet）
4. 配置模型参数（如R0、潜伏期等）
5. 点击"保存配置"
6. 配置保存到数据库的 `flu_model_config` 表

### 6.2 前端预测流程

1. 用户打开前端页面
2. 系统自动获取用户位置（城市）
3. 调用 `GET /api/public/model/config` 获取默认模型配置
4. 调用 `POST /api/public/predict` 进行预测：
   - 参数：`city_name`（用户所在城市）
   - 参数：`algorithm`（使用配置的默认算法）
5. 后端根据城市名称从数据库获取该城市的历史数据
6. 使用配置的默认模型进行预测
7. 返回预测结果给前端显示

## 八、使用步骤

### 步骤1：更新数据库

```bash
# 执行SQL脚本添加字段
mysql -u root -p Infectious_disease_data < backend/database/add_default_algorithm_column.sql
```

### 步骤2：重启后端服务

```bash
python backend/run.py
```

### 步骤3：配置默认模型

1. 登录后台管理系统
2. 访问"模型配置管理"页面
3. 选择默认预测算法
4. 保存配置

### 步骤4：前端自动使用

前端公众端会自动：
- 获取用户位置
- 使用配置的默认模型
- 根据位置获取对应城市的数据进行预测

## 九、注意事项

1. **数据库字段**：必须先执行SQL脚本添加 `default_algorithm` 字段
2. **权限控制**：只有超级管理员（username='admin'）可以修改模型配置
3. **前端缓存**：前端会在页面加载时获取配置，位置变化时会重新预测
4. **数据要求**：
   - SEIR：无需历史数据
   - LSTM：需要至少14天历史数据
   - Prophet：需要至少30天历史数据
